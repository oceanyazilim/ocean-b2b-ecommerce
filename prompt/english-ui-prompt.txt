# MASTER UI/UX DESIGN PROMPT

## Modern B2B Commerce Platform — Storefront, Admin Dashboard & Theme Builder

Design and implement a complete, production-grade UI/UX system for a modern B2B commerce SaaS platform.

The product should provide the operational depth of Shopify, but must NOT visually clone Shopify.

The final experience should feel like a modern commerce operating system built from the ground up for 2026.

The design direction should combine:

* Shopify-level commerce usability
* Linear-style interface clarity
* Stripe-style data presentation
* Vercel-style modern SaaS polish
* Strong B2B functionality
* Enterprise-grade information architecture
* Fast keyboard-driven workflows
* Minimal cognitive load
* High information density without visual clutter

The application should feel premium, calm, extremely responsive, professional and trustworthy.

---

---

# 2. GLOBAL DESIGN LANGUAGE

Create a clean, neutral and highly polished SaaS interface.

Do not overuse cards.

Do not create excessive gradients.

Do not create giant rounded containers everywhere.

Do not make the interface look like a generic startup dashboard template.

The interface should feel intentionally designed for commerce operations.

## Visual principles

Use:

* neutral background colors
* subtle borders
* extremely subtle shadows
* clear typography hierarchy
* restrained accent colors
* compact but comfortable spacing
* contextual status colors
* clear iconography
* clean tables
* sophisticated empty states
* lightweight animations
* high-quality hover states
* precise alignment

Prefer borders and surface contrast over large drop shadows.

Recommended visual characteristics:

Border radius:
6px–10px for most UI elements.

Large promotional surfaces:
12px–16px maximum.

Avoid excessive pill-shaped UI.

Buttons should be compact and functional.

Tables should feel dense but readable.

Forms should be clear and structured.
