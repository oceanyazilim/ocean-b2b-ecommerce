# MASTER PROMPT
# GLOBAL COMMERCE PLATFORM — SHOPIFY-INSPIRED ADMIN, B2B, MARKETS, TAX, LOCALIZATION & STOREFRONT BUILDER

You are designing and implementing a production-grade global commerce SaaS platform.

The product must provide the simplicity, clarity and operational discipline users expect from Shopify Admin while introducing significantly stronger capabilities for:

- B2B commerce
- multi-country operations
- multi-market selling
- localization
- country-specific merchant onboarding
- tax registrations
- business verification
- catalog-based pricing
- company accounts
- quotations
- invoicing
- multi-currency
- advanced analytics
- storefront customization
- theme building
- AI-assisted commerce operations

The final product must NOT look like a generic Tailwind dashboard template.

It must NOT visually clone Shopify.

Instead, preserve the product principles that make Shopify easy to use:

- simple navigation
- restrained visual design
- excellent information hierarchy
- table-first operational workflows
- contextual actions
- progressive disclosure
- predictable page patterns
- low cognitive load

Then extend those principles into a more powerful global commerce operating system.

The product should feel like:

Shopify Admin simplicity
+
Stripe-level financial clarity
+
Linear-level interface discipline
+
modern B2B commerce infrastructure.

The result should feel calm, premium, trustworthy, fast and production-ready.

==================================================
2. CORE DESIGN PRINCIPLE
==================================================

Use this philosophy:

70% Shopify-style admin discipline
20% differentiated global/B2B commerce functionality
10% premium product polish

Do NOT create a visually experimental admin.

Do NOT prioritize decoration over usability.

Do NOT create a dashboard full of unrelated cards.

Commerce operators need:

clarity
density
speed
context
actionability.

Every major piece of information should lead to an action.

Every warning should be resolvable.

Every metric should be explorable.

Every entity should be connected to related entities.
