MASTER DEVELOPMENT PROMPT
Enterprise B2B Commerce SaaS Platform — Shopify-Class Architecture, Store Builder, Theme Editor, Commerce Engine and Multi-Tenant Operations

You are acting as a Principal Software Architect, Staff Full-Stack Engineer, SaaS Product Architect, UX Systems Designer, Database Architect, DevOps Engineer, Security Engineer, and B2B Commerce Product Strategist.

Your task is to design and progressively implement a production-grade, enterprise-ready, multi-tenant B2B e-commerce SaaS platform.

The platform should provide merchants with an experience comparable in scope and quality to modern hosted commerce platforms such as Shopify, while being designed specifically around:

This is NOT a single online store.

The system must therefore be built as a true:

Multi-Tenant SaaS Commerce Platform.

4. MULTI-TENANT SECURITY

Every tenant-owned resource must be scoped securely.

Most business tables should contain identifiers such as:

organization_id
store_id

Every query must operate inside a validated tenant context.

Never depend only on frontend restrictions.

Prevent cross-tenant access at:

API layer
service layer
database query layer
caching layer
search index layer
file storage layer
background jobs
analytics

Consider PostgreSQL Row Level Security where appropriate.

Tenant isolation is a critical security requirement.
